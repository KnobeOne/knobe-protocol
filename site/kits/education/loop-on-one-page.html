The loop

The instructor designs and seals the sequence; students seal their steps against it; the TA checks the batch; disputes return to the instructor with a sealed record. Every arrow is a payload hash.

2 · Studentsseal their steps against it↓

4 · Back to the instructordisputes work from the sealed record↑

Three paths

Instructor

  1. Build and seal the sequence at knobe.org/studio (Journey tab).
  2. Post the journey file and its description to the Canvas assignment.
  3. Set the submission type to File Uploads.

Student

  1. Download the journey file attached to the assignment.
  2. Load it at knobe.org/studio, pick your step, write, and seal.
  3. Upload the sealed file to Canvas like any other file.

TA

  1. Download Submissions in Canvas and unzip.
  2. Drag the folder into Cohort check with the journey loaded.
  3. Read the table; export the CSV for the gradebook.

If the assignment restricts file types, the allowed list must include md, or Canvas rejects every submission. This is the most common setup failure.
